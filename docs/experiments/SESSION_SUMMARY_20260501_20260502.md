## Key Findings

### 1. The val leak was the noise generator, not the test set
EXP-023 measured cross-val std=0.015 on the 78-image val. EXP-029 measured 3-seed std=0.069 on the 50-image canonical_test_v2 — and we incorrectly attributed that 5× inflation to "smaller test set + different image mix." EXP-030's clean-split std came back to 0.014 — confirming the test set was never the problem. **The val leak was amplifying single-seed variance** because best.pt was being selected on test-leaked val.

### 2. The QA cleanup may not have actually moved mAP50
Three honest possibilities:
- (a) QA cleanup had near-zero effect on this model
- (b) Real but smaller than 0.014 noise floor at n=3
- (c) Cancelled out by 9% data reduction (508→460 train when test images excluded)
We can't disentangle (b) from (c) without retraining on 460 unmodified April labels. The labels are visually demonstrably more correct (~80% of v7_auto had real bbox errors), but the metric doesn't see it.

### 3. SAHI is the wrong tool for our test set
Sliced inference fragments large signs across slices. Canonical_test_v2 has prominent signs, so SAHI hurts. Reserve SAHI for a future "distant approach phase" eval set if/when one is built.

### 4. Methodology > headline numbers
We had EXP-021d at 0.760 mAP50 on a 25-image leaky test. EXP-024a at 0.649 on a 50-image leaky test. EXP-030 at 0.692 on a 50-image clean test. The clean number is the only one we'd defend in print, even though it's not the highest. Worth absorbing this as a project discipline going forward.
