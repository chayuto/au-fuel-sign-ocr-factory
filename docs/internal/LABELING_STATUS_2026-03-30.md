## Quality Problem

Of the 149 labeled images, only **22 were actually visually verified**. We confirmed this by checking which preview files were individually regenerated after the bulk `draw_annotations.py` run (i.e., an agent actually re-drew and re-read the preview).

| Workflow | Count | Visual QA | Quality |
|----------|------:|-----------|---------|
| Confirmed visual QA (preview individually regenerated) | **22** | Yes | Verified — agent read preview, fixed errors |
| Normalizer (schema migration) | 46 | No | Coords migrated from 5 JSON variants, never visually checked |
| Agents 11, 13, 14 (alt manifest batch) | 54 | No | Reconciled from wrong manifest file, blind estimation |
| Agents 7, 9, 10, 12 (bulk manifest update) | 27 | No | Manifest timestamps suggest bulk update, not per-image verify |

**How we verified:** Preview files modified *after* the bulk `draw_annotations.py --all` run are the ones where an agent individually regenerated and inspected the preview. Only 22 out of 149 meet this criterion.

`au_fuel_carexpert_bp_station`, `au_fuel_carexpert_fuel_pump`, `au_fuel_carsales_diesel_price_board`, `au_fuel_carsguide_bp`, `au_fuel_cvmedia_otr`, `au_fuel_news_aap_station_3`, `au_fuel_sample_01_abc_united`, `au_fuel_sample_03_9news_bp`, `au_fuel_sample_05_alamy_shell_coles`, `au_fuel_sample_06_axent_led`, `au_fuel_sample_07_9news_station`, `au_fuel_sample_08_7eleven`, `au_fuel_sample_09_sydneyled_product1`, `au_fuel_sample_12_sydneyled_overview`, `au_fuel_sample_12_sydneyled_overview_full`, `au_fuel_sample_20_pacific_petroleum_1`, `au_fuel_sample_25_united_bethania_2`, `au_fuel_sample_31_mobil_kembla`, `au_fuel_sample_32_mobil_faulconbridge`, `au_fuel_sample_33_mobil_kembla2`, `au_fuel_sample_34_pylon_generic`, `au_fuel_sample_35_caltex_northlakes_1`

### Phase 1: Re-label 127 unverified images (HIGH PRIORITY)

These 127 images have annotations but were labeled without visual verification. Based on the test run (100% error rate on re-checked images), they are almost certainly all wrong.

| Agent batch | Count | Action |
|-------------|------:|--------|
| `normalizer` | 46 | Re-label with visual QA |
| `agent_11` | 16 | Re-label with visual QA |
| `agent_13` | 21 | Re-label with visual QA |
| `agent_14` | 17 | Re-label with visual QA |
| `agent_7, 9, 10, 12` (bulk-updated, not verified) | 27 | Re-label with visual QA |

**Approach:** Launch 5-8 Sonnet agents at a time, 1 image per agent. Each agent:
1. Reads the image
2. Ignores the existing annotation — starts fresh
3. Annotates with visual QA (preview + verify)
4. Logs to `labeling_log.jsonl` with action `corrected` or `relabeled`

**Estimated cost:** 127 images x ~45K tokens x ~$0.003/1K = ~$17
**Estimated time:** 127 images / 6 parallel agents x ~300s = ~106 min wall time
